# Архивные растения и их история

Проверка 2026-10-15 по коду ветки `agent/daily` (бэклог, задача 3). Код не
менялся.

## Что есть сейчас

- «убрать» (`del` → `delok` в `handlers.ts`) не удаляет растение, а ставит
  `plants.archived = true`. Комментарий в коде: удаление стёрло бы историю
  каскадом (`events.plant_id … on delete cascade`).
- История лежит в `events`: `water`, `feed`, `rain`, `diagnosis`, `note`,
  `photo` (с `photo_file_id`) и `created_at`. Для архивных она сохраняется.
- Посмотреть архив в боте **нельзя**: `db.plants()` и `db.plant()` отдают
  только `archived = false`. Списка архива, кнопки «вернуть» и экрана
  истории нет. `db.plant()` отсекает архивные намеренно, чтобы старые кнопки
  в чате не открывали убранное растение.
- Экрана истории нет и у живых растений: карточка показывает только
  последний полив, `/week` — поливы текущей недели.

Итого: данные на месте (их видно в Supabase через таблицы `plants` и
`events`), в самом боте их не видно.

## Как сделать (без изменения текущего поведения)

1. `db.ts`: `archivedPlants(uid)` (тот же запрос с `archived = true`,
   сортировка по дате убирания), `archivedPlant(uid, id)` и
   `plantEvents(uid, id, limit)` (последние N событий, новые сверху).
   `db.plant()` не трогать.
2. Вход: строка «архив · N» внизу «весь сад» (`list`), только если N > 0.
   Колбэк `arc`, у одного архивного — `arp:<id>`. Длина колбэка ≤ 64 байт,
   uuid 36, укладывается.
3. Карточка архивного: имя, комната, когда добавлено и когда убрано, затем
   история строками «12 окт · полито», «3 окт · фото». Фото — из
   `plants.photo_file_id`, как в обычной карточке.
4. Кнопки: «вернуть в сад» (`unarc:<id>` → `archived = false`) и «назад».
   Удалить насовсем — не делать без решения: это сотрёт историю.
5. Для дня убирания нужно поле `archived_at` (миграция `alter table plants
   add column archived_at timestamptz`), иначе дату взять неоткуда. Можно и
   без миграции, тогда дата не показывается.
6. Тексты экранов — в `texts.ts`. Тест — запросы `db` на моке, как в
   `watering_test.ts`.

Объём: около 120 строк, одна миграция по желанию.

## Развилки для Алисы

- Нужен ли архив в боте вообще, или хватит вида в Supabase.
- История только у архивных или у всех растений (кнопка «история» в «инфо»).
- Добавлять ли `archived_at` (миграция) или жить без даты убирания.
